# myoML

## Introduction

## Pre-requisites
You will need an installation of Python v3.13.7 to run the code for this project. 

## Downloading the data
The data used for this project can be found [here](https://unioxfordnexus-my.sharepoint.com/personal/wolf6273_ox_ac_uk/_layouts/15/onedrive.aspx?id=%2Fpersonal%2Fwolf6273%5Fox%5Fac%5Fuk%2FDocuments%2FData&ga=1). Download the folder and unzip it in the `/data` folder.

## Setting up the virtual environment
Set up a virtual environment and install all the required packages by running the below in a terminal window:

```
python3 -m venv venv
source ./venv/bin/activate
pip install -r requirements.txt
```
